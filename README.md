## Layout
```
docs/rules/          Traders Handbook (PDF + text). Source of truth for rules.
data/raw/            Original files exactly as received. NEVER edit.
data/processed/      Clean CSVs generated by scripts (wls_universe, country weights).
portfolio/
  positions.csv      What we hold right now (mirror of TMSG).
  trades.csv         Every buy/sell ever, with reason + actual fill.
tracking/
  leaderboard.csv    Weekly rank / Rel / Abs P&L snapshots (ours + rivals).
  daily_pnl.csv      Daily Abs/Rel P&L, cash, Nifty, USDINR.
research/
  watchlist.csv      Every idea ever mentioned + whether it's in WLS + status.
  stocks/<TICKER>.md One thesis file per stock (copy _TEMPLATE.md).
journal/YYYY-MM-DD.md  Daily notes, chat decisions, open questions.
strategy/            STATUS (current state), rules/checklist, plan.
scripts/             Helpers (below).
```

## Scripts
```bash
pip install pandas openpyxl
python scripts/build_universe.py           # raw WLS xlsx -> data/processed/*.csv
python scripts/wls.py "reliance" "LULU"    # is it in WLS? exact ticker?
python scripts/check_portfolio.py          # rule check + country exposure vs benchmark
```

## Conventions
- Dates `YYYY-MM-DD`. Tickers in Bloomberg form (`RELIANCE IS Equity`).
- Money in **USD** (that's what TMSG scores). Local prices tagged `_local`.
- Anything unconfirmed is written as unconfirmed — never guess numbers into the ledger.
- Commit after each trading session: `git add -A && git commit -m "YYYY-MM-DD: ..." && git push`.
